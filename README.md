### `Real-Time Data Loss Prevention (DLP) Agent`

An air-gapped security agent that monitors the screen buffer in real-time using local OCR and AI pattern matching to detect and prevent visual secret exfiltration.

### ✨ What it can do

| Feature             | Description                                      |
| ------------------- | ------------------------------------------------ |
| 🛡️ Zero-Cloud DLP   | Operates 100% locally with zero external network telemetry |
| ⚡ Low-Latency OCR  | Sub-100ms optical inspection via optimized OpenCV |
| 🔑 Secret Detector  | Automatically flags API keys, AWS secrets, and PII |
| 🚨 Auto Mitigation  | Triggers kill-switch alerts upon sensitive visual match |
| 📊 Threat Scoring   | Contextually evaluates severity of captured visual buffers |
| 📥 Event Logging    | Outputs encrypted local security event logs      |

### ⚙️ Built With

`Python` `OpenCV` `PyTesseract` `Scikit-learn` `Regex Engine`
